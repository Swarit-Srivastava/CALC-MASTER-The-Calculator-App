# Calc Master 🧮

**Calc Master** is a sleek, modern, and interactive web-based calculator application built using vanilla **HTML**, **CSS**, and **JavaScript**. Featuring a clean dark-mode interface with vibrant yellow accents, it provides an intuitive user experience for everyday calculations.

## ✨ Features

* **Modern Dark Theme UI**: Designed with a professional dark-slate background and bright yellow highlights for high visibility[cite: 1].
* **Navigation Bar**: Includes a clean top navigation header with **Home**, **About**, and **Contact** links[cite: 1].
* **Comprehensive Keypad**: 
  * Standard arithmetic operations (`+`, `-`, `x`, `/`)[cite: 1]
  * Percentage (`%`) and decimal point calculations[cite: 1]
  * Utility keys like All Clear (`AC`), Delete (`DEL`), and a double-zero (`00`) shortcut[cite: 1].
* **Responsive Design**: Built to render cleanly across different devices and screen sizes.

## 🛠️ Tech Stack

* **HTML5**: Semantic markup for structuring the application layout.
* **CSS3**: Styling, custom color palettes, flexbox/grid alignments, and visual effects.
* **JavaScript**: Dynamic calculation logic, screen updates, and button event handling.
